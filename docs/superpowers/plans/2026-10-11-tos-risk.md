# ToS Risk Uzantısı — Uygulama Planı

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Kullanım koşulları/gizlilik/abonelik sayfasını okuyup alıntıyla doğrulanmış, kodla puanlanmış Türkçe risk raporu gösteren Chrome uzantısı + 5 belgelik eval + Cypress demo videosu.

**Architecture:** page-agent'ın `@page-agent/page-controller` paketi sayfanın görünür metnini çıkarır (content script). Metin background'a gider, orada Gemini'ye JSON şemayla sorulur. `src/core/` içindeki saf JS hattı çıktıyı zod ile doğrular, alıntıları metinde arar, skoru kodla hesaplar ve belirsizliğe karar verir. Rapor sayfada Shadow DOM panelde gösterilir. `core/` tarayıcı API'si kullanmaz, vitest ve eval aynı kodu Node'da çalıştırır.

**Tech Stack:** Node 24, düz JavaScript (ESM), esbuild, zod 4, vitest + jsdom, Cypress 16 + Chrome for Testing, Gemini (OpenAI uyumlu uç).

**Spec:** `docs/superpowers/specs/2026-10-11-tos-risk-design.md`

## Global Constraints

- Teslim 16 Ekim 2026, bireysel. Spec dışında özellik eklenmez.
- Tüm kullanıcıya görünen metinler Türkçe.
- LLM: `https://generativelanguage.googleapis.com/v1beta/openai/chat/completions`, varsayılan model `gemini-3.8-flash`, `temperature: 0`, `response_format: { type: "json_schema" }`.
- API anahtarı repoya asla girmez. Uzantıda `chrome.storage.local`, eval'de `GEMINI_API_KEY` ortam değişkeni, test derlemesinde (`dist-test/`, gitignore'da) esbuild `define`.
- Alıntı en az 20 karakter. Normalize edilmiş metinde birebir bulunmazsa madde doğrulanmamış sayılır.
- Skor ağırlıkları: data_sharing 25, auto_renewal 20, arbitration_waiver 20, unilateral_change 15, content_license 15, refund_cancel 15, account_termination 10, liability_limit 10. Şiddet çarpanı low 0.5 / medium 1 / high 1.5. Kategori başına bir kez (en yüksek şiddet), toplam 100'de kesilir. Seviye: <30 düşük, <60 orta, ≥60 yüksek.
- Belirsizlik eşikleri: metin < 1500 karakter; metin > 120000 karakter (kesilir); `is_legal_document: false`; doğrulanamayan maddeler yarıdan fazla; çıkarılan metinde injection kalıbı.
- LLM çıktısı panelde asla `innerHTML` ile basılmaz, yalnızca text node olarak eklenir.
- Disclaimer metni (her raporda ve popup'ta): "Bu araç hukuki tavsiye vermez. Sonuçlar otomatik üretilmiştir ve hatalı olabilir; önemli kararlar için bir hukukçuya danışın."

## Review Focus

1. **Panelin kendi metni analize karışması:** Panel açıkken çıkarılan metne panel yazıları, hatta önceki raporun alıntıları girerse alıntılar kendini doğrular. Beklenen: çıkarma ve `textContent` okuma sırasında panel DOM'dan ayrılır. Task 6'da `withDetached` testiyle sabitlenir.
2. **LLM çıktısında HTML/script (injection'dan gelebilir):** Beklenen: metin olarak görünür, element oluşmaz. Task 6'da XSS testiyle sabitlenir.
3. **Belge içinde `</document>` geçmesi (sınır kaçırma):** Beklenen: etiket metinden silinir. Task 4'te test edilir.
4. **Ağ/anahtar hatası (401, 429, çevrimdışı):** Beklenen: panel "yükleniyor"da takılmaz, Türkçe hata gösterir. Task 5'te `complete` hata fırlatınca `status: 'failed'` testiyle sabitlenir.
5. **Çok uzun ToS (> 120000 karakter):** Beklenen: kesilir ve belirsizlik sebebi olarak yazılır. Task 5'te test edilir.

```js
// Sayfa metni ve alıntılar aynı kurallarla normalize edilir; karşılaştırma bu
// iki normalize metin arasında yapılır.
export function normalize(s) {
  return s
    .normalize('NFKC')
    .replace(/[‘’‚‛′]/g, "'")
    .replace(/[“”„‟″]/g, '"')
    .replace(/[‐-―−]/g, '-')
    .toLowerCase()
    .replace(/̇/g, '') // "İ".toLowerCase() → "i̇"
    .replace(/ı/g, 'i') // "I" → "i" ile tutarlı olsun
    .replace(/\s+/g, ' ')
    .trim();
}

// page-controller çıktısındaki "[12]<a ...>" ve "</a>" işaretlerini siler.
export function stripMarkers(s) {
  return s.replace(/\[\d+\]<[^>]*>/g, '').replace(/<\/?[a-z][^>]*>/gi, '');
}
```

`src/core/quotes.js`:
```js
import { normalize } from './text.js';

export const MIN_QUOTE_LENGTH = 20;

export function quoteSpan(quote, normalizedDoc) {
  const q = normalize(quote);
  if (q.length < MIN_QUOTE_LENGTH) return null;
  const start = normalizedDoc.indexOf(q);
  return start === -1 ? null : { start, end: start + q.length };
}

export function verifyQuote(quote, normalizedDoc) {
  return quoteSpan(quote, normalizedDoc) !== null;
}
```

`src/core/schema.js`:
```js
import { z } from 'zod';

export const CATEGORIES = [
  'auto_renewal', 'data_sharing', 'unilateral_change', 'arbitration_waiver',
  'account_termination', 'liability_limit', 'content_license', 'refund_cancel',
];

const ClauseSchema = z.object({
  category: z.enum(CATEGORIES),
  severity: z.enum(['low', 'medium', 'high']),
  quote: z.string().min(1),
  explanation_tr: z.string().min(1),
  advice_tr: z.string().min(1),
});

export const LlmOutputSchema = z.object({
  is_legal_document: z.boolean(),
  document_type: z.enum(['tos', 'privacy', 'subscription', 'other']),
  summary_tr: z.string(),
  clauses: z.array(ClauseSchema).max(30),
});

// Gemini'ye gönderilen şema aynı zod tanımından üretilir; tek kaynak.
const { $schema, ...jsonSchema } = z.toJSONSchema(LlmOutputSchema);
export const llmJsonSchema = jsonSchema;

export function parseLlmOutput(raw) {
  let data;
  try {
    data = JSON.parse(raw);
  } catch (e) {
    return { ok: false, error: `Yanıt geçerli JSON değil: ${e.message}` };
  }
  const result = LlmOutputSchema.safeParse(data);
  return result.success
    ? { ok: true, data: result.data }
    : { ok: false, error: z.prettifyError(result.error) };
}
```

`src/core/score.js`:
```js
export const WEIGHTS = {
  data_sharing: 25,
  auto_renewal: 20,
  arbitration_waiver: 20,
  unilateral_change: 15,
  content_license: 15,
  refund_cancel: 15,
  account_termination: 10,
  liability_limit: 10,
};

export const SEVERITY_MULTIPLIER = { low: 0.5, medium: 1, high: 1.5 };

export function levelFor(score) {
  if (score >= 60) return 'high';
  if (score >= 30) return 'medium';
  return 'low';
}

// Skor yalnızca doğrulanmış maddelerden hesaplanır; LLM skor üretmez.
export function computeScore(clauses) {
  const best = {};
  for (const { category, severity } of clauses) {
    best[category] = Math.max(best[category] ?? 0, SEVERITY_MULTIPLIER[severity]);
  }
  const total = Object.entries(best).reduce((sum, [cat, m]) => sum + WEIGHTS[cat] * m, 0);
  const score = Math.min(100, Math.round(total));
  return { score, level: levelFor(score) };
}
```

```js
import { normalize } from './text.js';

// Kalıplar normalize edilmiş metne uygulanır (küçük harf, ı→i).
const PATTERNS = [
  /ignore (all |any )?(of )?(the |your )?(previous|prior|above|earlier) (instructions|prompts?|rules)/,
  /disregard (all |any )?(of )?(the |your )?(previous|prior|above|earlier)/,
  /\byou are now\b/,
  /\bsystem prompt\b/,
  /(önceki|yukaridaki) (tüm )?talimatlari (yok say|unut|dikkate alma|görmezden gel)/,
  /risk (skoru|score)[^.\n]{0,30}\b(0|sifir|zero)\b/,
  /(do not|don't|never) (report|flag|mention|list) (any )?(risks?|clauses?)/,
  /hiçbir (risk|riskli madde|madde)[^.\n]{0,20}(bildirme|raporlama|gösterme|listeleme)/,
];

export function detectInjection(text) {
  const t = normalize(text);
  const found = new Set();
  for (const p of PATTERNS) {
    for (const m of t.matchAll(new RegExp(p.source, 'g'))) found.add(m[0]);
  }
  return [...found];
}
```

```js
export const GEMINI_URL = 'https://generativelanguage.googleapis.com/v1beta/openai/chat/completions';
export const DEFAULT_MODEL = 'gemini-3.8-flash';

export function createGeminiClient({ apiKey, model = DEFAULT_MODEL, fetchImpl = (...a) => fetch(...a) }) {
  return async function complete(messages, jsonSchema) {
    const res = await fetchImpl(GEMINI_URL, {
      method: 'POST',
      headers: { 'Content-Type': 'application/json', Authorization: `Bearer ${apiKey}` },
      body: JSON.stringify({
        model,
        messages,
        temperature: 0,
        response_format: { type: 'json_schema', json_schema: { name: 'tos_risk_report', schema: jsonSchema } },
      }),
    });
    if (!res.ok) {
      throw new Error(`Gemini HTTP ${res.status}: ${(await res.text()).slice(0, 300)}`);
    }
    const body = await res.json();
    return body.choices?.[0]?.message?.content ?? '';
  };
}
```

```js
import { normalize, stripMarkers } from './text.js';
import { verifyQuote } from './quotes.js';
import { parseLlmOutput, llmJsonSchema } from './schema.js';
import { computeScore } from './score.js';
import { detectInjection } from './injection.js';
import { buildMessages } from './prompt.js';

export const MIN_CHARS = 1500;
export const MAX_CHARS = 120000;

async function askWithRetry(complete, messages) {
  const first = parseLlmOutput(await complete(messages, llmJsonSchema));
  if (first.ok) return first;
  const retry = [
    ...messages,
    { role: 'user', content: `Önceki yanıtın şemaya uymadı: ${first.error}\nYalnızca şemaya uygun JSON döndür.` },
  ];
  return parseLlmOutput(await complete(retry, llmJsonSchema));
}

export async function analyzeDocument({ text, complete, rawPageText = '' }) {
  const clean = stripMarkers(text);
  const truncated = clean.length > MAX_CHARS;
  const docText = truncated ? clean.slice(0, MAX_CHARS) : clean;

  let parsed;
  try {
    parsed = await askWithRetry(complete, buildMessages(docText));
  } catch (e) {
    return { status: 'failed', error: e.message };
  }
  if (!parsed.ok) return { status: 'failed', error: `Model geçerli rapor üretemedi. ${parsed.error}` };

  const out = parsed.data;
  const normDoc = normalize(docText);
  const clauses = [];
  const unverified = [];
  for (const c of out.clauses) (verifyQuote(c.quote, normDoc) ? clauses : unverified).push(c);

  const { score, level } = computeScore(clauses);
  const inText = detectInjection(docText);
  const hiddenOnly = detectInjection(rawPageText).filter((m) => !inText.includes(m));

  const reasons = [];
  if (clean.length < MIN_CHARS) reasons.push('Metin çok kısa; sözleşmenin tamamı bu sayfada olmayabilir.');
  if (truncated) reasons.push(`Metin çok uzun; yalnızca ilk ${MAX_CHARS} karakter incelendi.`);
  if (!out.is_legal_document) reasons.push('Bu sayfa bir sözleşme veya politika metnine benzemiyor.');
  if (out.clauses.length > 0 && unverified.length * 2 > out.clauses.length) {
    reasons.push('Modelin iddialarının yarısından fazlası metinde doğrulanamadı.');
  }
  if (inText.length > 0) {
    reasons.push('Metinde yapay zekâya yönelik talimat benzeri ifadeler var; model etkilenmiş olabilir.');
  }

  return {
    status: 'ok',
    isLegalDocument: out.is_legal_document,
    documentType: out.document_type,
    summary: out.summary_tr,
    score,
    level,
    clauses,
    unverified,
    uncertain: reasons.length > 0,
    uncertaintyReasons: reasons,
    injection: { inText, hiddenOnly },
  };
}
```

```js
function el(tag, attrs = {}, ...children) {
  const node = document.createElement(tag);
  for (const [k, v] of Object.entries(attrs)) {
    if (k === 'onclick') node.addEventListener('click', v);
    else node.setAttribute(k, v);
  }
  for (const c of children.flat()) node.append(c instanceof Node ? c : document.createTextNode(String(c)));
  return node;
}

function renderClause(c, testid) {
  return el('div', { class: 'clause', 'data-testid': testid },
    el('div', { class: 'cat' }, `${CATEGORY_TR[c.category]} · ${SEVERITY_TR[c.severity]} şiddet`),
    el('blockquote', { 'data-testid': 'tos-quote' }, c.quote),
    el('p', {}, c.explanation_tr),
    el('p', { class: 'advice' }, `Öneri: ${c.advice_tr}`));
}

function renderReport(r, onAnalyze) {
  if (r.status !== 'ok') {
    return [
      el('p', { class: 'error', 'data-testid': 'tos-error' }, `Analiz yapılamadı: ${r.error}`),
      el('button', { onclick: onAnalyze }, 'Tekrar dene'),
    ];
  }
  const nodes = [
    el('div', { class: `score ${r.level}`, 'data-testid': 'tos-score', 'data-score': String(r.score) },
      `Risk skoru: ${r.score}/100 · ${LEVEL_TR[r.level]}`),
  ];
  if (r.uncertain) {
    nodes.push(el('div', { class: 'uncertain', 'data-testid': 'tos-uncertain' },
      el('strong', {}, 'Emin değilim. Bu sonuca temkinli yaklaşın:'),
      el('ul', {}, r.uncertaintyReasons.map((x) => el('li', {}, x)))));
  }
  const inj = [...r.injection.inText, ...r.injection.hiddenOnly.map((m) => `${m} (gizli metinde; analize alınmadı)`)];
  if (inj.length > 0) {
    nodes.push(el('div', { class: 'warn', 'data-testid': 'tos-injection-warning' },
      el('strong', {}, 'Sayfada yapay zekâya yönelik talimat bulundu.'),
      el('p', {}, 'Bu talimatlar uygulanmadı. Skor, modelin değil kodun hesabıdır ve yalnızca metinde doğrulanmış alıntılara dayanır.'),
      el('ul', {}, inj.map((x) => el('li', {}, x)))));
  }
  nodes.push(el('p', { 'data-testid': 'tos-summary' }, r.summary));
  if (r.clauses.length === 0) nodes.push(el('p', {}, 'Doğrulanmış riskli madde bulunamadı.'));
  nodes.push(...r.clauses.map((c) => renderClause(c, 'tos-clause')));
  if (r.unverified.length > 0) {
    nodes.push(el('details', { 'data-testid': 'tos-unverified' },
      el('summary', {}, `Doğrulanamayan iddialar (${r.unverified.length}): alıntı metinde bulunamadı, skora katılmadı`),
      r.unverified.map((c) => renderClause(c, 'tos-unverified-clause'))));
  }
  return nodes;
}

export function createPanel(parent, { onAnalyze }) {
  const host = document.createElement('div');
  host.id = 'tos-risk-host';
  host.style.cssText = 'all:initial;position:fixed;top:16px;right:16px;z-index:2147483647;width:380px';
  const root = host.attachShadow({ mode: 'open' });
  const body = el('div', { class: 'body' });
  root.append(el('style', {}, CSS),
    el('div', { class: 'box', 'data-testid': 'tos-panel' },
      el('p', { class: 'disclaimer', 'data-testid': 'tos-disclaimer' }, DISCLAIMER), body));
  parent.append(host);

  const set = (...nodes) => body.replaceChildren(...nodes.flat());
  return {
    host,
    root,
    showIntro() {
      set(el('p', {}, 'Bu sayfa bir kullanım koşulu / gizlilik / abonelik metnine benziyor.'),
        el('button', { 'data-testid': 'tos-analyze-btn', onclick: onAnalyze }, 'Riskleri analiz et'));
    },
    showLoading() {
      set(el('p', { 'data-testid': 'tos-loading' }, 'Metin okunuyor ve analiz ediliyor…'));
    },
    showReport(report) {
      set(renderReport(report, onAnalyze));
    },
    // Metin çıkarılırken panelin kendi yazıları (ve eski alıntılar) analize karışmasın.
    async withDetached(fn) {
      host.remove();
      try {
        return await fn();
      } finally {
        parent.append(host);
      }
    },
  };
}
```

```js
import { isLegalPage } from '../core/detect.js';
import { createPanel } from './panel.js';

let panel = null;
const getPanel = () => (panel ??= createPanel(document.body, { onAnalyze: runAnalysis }));

// page-agent'ın DOM okuyucusu: görünür metni çıkarır.
async function extractText() {
  const pc = new PageController({ viewportExpansion: -1 });
  try {
    const state = await pc.getBrowserState();
    return state.content;
  } finally {
    await pc.cleanUpHighlights();
    pc.dispose();
  }
}

async function runAnalysis() {
  const p = getPanel();
  try {
    const { text, rawPageText } = await p.withDetached(async () => ({
      text: await extractText(),
      rawPageText: document.body.textContent ?? '',
    }));
    p.showLoading();
    p.showReport(await chrome.runtime.sendMessage({ type: 'analyze', text, rawPageText }));
  } catch (e) {
    p.showReport({ status: 'failed', error: e.message ?? String(e) });
  }
}

if (isLegalPage(location.href, document.title)) {
  chrome.runtime.sendMessage({ type: 'legal-page-detected' });
  getPanel().showIntro();
}

chrome.runtime.onMessage.addListener((msg) => {
  if (msg.type === 'start-analysis') runAnalysis();
```

```js
import { quoteSpan } from '../src/core/quotes.js';

const overlaps = (a, b) => a && b && a.start < b.end && b.start < a.end;

// Eşleşme: aynı kategori ve alıntıların metindeki konumları örtüşüyor.
export function matchClauses(predicted, gold, normalizedDoc) {
  const goldSpans = gold.map((x) => quoteSpan(x.quote, normalizedDoc));
  const used = new Set();
  const caught = [];
  const falseAlarms = [];
  const duplicates = [];
  for (const p of predicted) {
    const ps = quoteSpan(p.quote, normalizedDoc);
    const hits = gold
      .map((x, i) => i)
      .filter((i) => gold[i].category === p.category && overlaps(ps, goldSpans[i]));
    const free = hits.find((i) => !used.has(i));
    if (free !== undefined) {
      used.add(free);
      caught.push({ predicted: p, gold: gold[free] });
    } else if (hits.length > 0) {
      duplicates.push(p);
    } else {
      falseAlarms.push(p);
    }
  }
  const missed = gold.filter((_, i) => !used.has(i));
  return { caught, missed, falseAlarms, duplicates };
}
```

```js
import { readFileSync, writeFileSync, mkdirSync } from 'node:fs';
import { analyzeDocument } from '../src/core/analyze.js';
import { createGeminiClient, DEFAULT_MODEL } from '../src/core/llm.js';
import { normalize } from '../src/core/text.js';
import { matchClauses } from './match.js';

const apiKey = process.env.GEMINI_API_KEY;
if (!apiKey) {
  console.error('GEMINI_API_KEY gerekli.');
  process.exit(1);
}
const model = process.env.GEMINI_MODEL || DEFAULT_MODEL;
const complete = createGeminiClient({ apiKey, model });
const sources = JSON.parse(readFileSync('eval/sources.json', 'utf8'));
mkdirSync('eval/out', { recursive: true });

const rows = [];
for (const s of sources) {
  const text = readFileSync(`eval/docs/${s.id}.txt`, 'utf8');
  const gold = JSON.parse(readFileSync(`eval/gold/${s.id}.json`, 'utf8')).clauses;
  console.log(`Analiz: ${s.name}`);
  const report = await analyzeDocument({ text, complete });
  writeFileSync(`eval/out/${s.id}.json`, JSON.stringify(report, null, 2));
  rows.push({ s, gold, report, m: report.status === 'ok' ? matchClauses(report.clauses, gold, normalize(text)) : null });
}

const pct = (a, b) => (b === 0 ? '—' : `${Math.round((100 * a) / b)}%`);
const ok = rows.filter((r) => r.m);
const sum = (f) => ok.reduce((n, r) => n + f(r), 0);
const C = sum((r) => r.m.caught.length);
const M = sum((r) => r.m.missed.length);
const F = sum((r) => r.m.falseAlarms.length);

const lines = [
  '# Eval sonuçları',
  '',
  `Tarih: ${new Date().toISOString().slice(0, 10)} · Model: \`${model}\` · temperature 0 · tek çalıştırma`,
  '',
  'Eşleşme: aynı kategori ve alıntının metindeki konumu altın alıntıyla örtüşüyor. Doğrulanamayan (metinde bulunamayan) iddialar rapora girmediği için yanlış alarm sayılmaz, ayrı sütunda gösterilir.',
  '',
  '| Belge | Altın | Yakalanan | Kaçırılan | Yanlış alarm | Tekrar | Doğrulanamayan | Skor | Belirsiz |',
  '|---|---|---|---|---|---|---|---|---|',
  ...rows.map(({ s, gold, report, m }) => (m
    ? `| ${s.name} | ${gold.length} | ${m.caught.length} | ${m.missed.length} | ${m.falseAlarms.length} | ${m.duplicates.length} | ${report.unverified.length} | ${report.score} | ${report.uncertain ? 'evet' : 'hayır'} |`
    : `| ${s.name} | ${gold.length} | — | — | — | — | — | analiz başarısız: ${report.error} | — |`)),
  '',
  `**Toplam:** yakalanan ${C}, kaçırılan ${M}, yanlış alarm ${F} · precision ${pct(C, C + F)} · recall ${pct(C, C + M)}`,
  '',
];
for (const { s, m } of ok) {
  lines.push(`## ${s.name}`, '', `Kaynak: ${s.url} (alındı: ${s.retrieved})`, '');
  if (m.missed.length) lines.push('**Kaçırılan:**', ...m.missed.map((x) => `- [${x.category}] "${x.quote}"`), '');
  if (m.falseAlarms.length) lines.push('**Yanlış alarm:**', ...m.falseAlarms.map((x) => `- [${x.category}] "${x.quote}"`), '');
}
writeFileSync('eval/RESULTS.md', lines.join('\n'));
console.log(`precision ${pct(C, C + F)} · recall ${pct(C, C + M)} → eval/RESULTS.md`);
```
